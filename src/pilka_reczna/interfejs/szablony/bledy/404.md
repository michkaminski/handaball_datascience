# Nie znaleziono — HTTP 404

Status: projekt szablonu. Plik `404.html` nie został jeszcze utworzony. Ten MD będzie znajdował się obok niego i będzie aktualizowany wraz ze zmianą szablonu.

Docelowy szablon względem katalogu szablony: `bledy/404.html`.

## Przeznaczenie

Informacja o nieistniejącym obiekcie lub adresie oraz możliwość powrotu.

## Dane wejściowe

Bezpieczny komunikat i odnośnik powrotu. Nie wymaga znalezionego obiektu domenowego.

## Powiązania

Obsługa błędów HTTP, w tym NieZnalezionoMeczu; układ baza.html. Odpowiedź musi mieć status 404.

## Gdzie wprowadzać zmiany

Tutaj zmieniaj komunikat i akcję powrotu. Wykrywanie braku meczu pozostaje w kontrakcie repozytorium i warstwie HTTP.

## Sprawdzenie zmiany

Sprawdź nieznany identyfikator, nieznany adres, poprawny status HTTP oraz niezależność renderowania od dostępności danych.

## Stan implementacji

Nie ma jeszcze bloków Jinja2, selektorów CSS ani powiązań JS do potwierdzenia. Przy implementacji zastąp ten zapis rzeczywistymi nazwami bloków, selektorów i plików testów; nie wpisuj planowanych kontroli jako wykonanych.
