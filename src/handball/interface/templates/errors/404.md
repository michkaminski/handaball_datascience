# Nie znaleziono — HTTP 404

Status: projekt szablonu. Plik `404.html` nie został jeszcze utworzony. Ten MD będzie znajdował się obok niego i będzie aktualizowany wraz ze zmianą szablonu.

Docelowy szablon względem katalogu szablony: `errors/404.html`.

## Przeznaczenie

Informacja o nieistniejącym obiekcie lub adresie oraz możliwość powrotu.

## Dane wejściowe

Bezpieczny komunikat i odnośnik powrotu. Nie wymaga znalezionego obiektu domenowego.

## Powiązania

Obsługa błędów HTTP, w tym NieZnalezionoMeczu; układ base.html. Odpowiedź musi mieć status 404.

## Gdzie wprowadzać zmiany

Tutaj zmieniaj komunikat i akcję powrotu. Wykrywanie braku meczu pozostaje w kontrakcie repozytorium i warstwie HTTP.

## Sprawdzenie zmiany

Sprawdź nieznany identyfikator, nieznany adres, poprawny status HTTP oraz niezależność renderowania od dostępności danych.

## Stan implementacji

Nie ma jeszcze bloków Jinja2, selektorów CSS ani powiązań JS do potwierdzenia. Przy implementacji zastąp ten zapis rzeczywistymi nazwami bloków, selektorów i plików testów; nie wpisuj planowanych kontroli jako wykonanych.

## Układ tekstowy i mapa zmian

Stan: **plan — brak odpowiadającego HTML**. Poniżej tekstowa mapa zakresu z dotychczasowej notatki, nie zatwierdzony projekt rozmieszczenia pól.

```text
[planowana wspólna rama: base.html]
+------------------------------------------------------------+
| Nie znaleziono — 404
| [bezpieczny komunikat braku obiektu lub adresu]
| [odnośnik powrotu — do ustalenia]
+------------------------------------------------------------+
[planowana stopka wspólnego układu]
```

Obecnie używana jest domyślna strona Flaska. Dokładny układ własnej strony oraz odnośnik powrotu nie są jeszcze zaimplementowane.

Układ mobilny, dokładne etykiety i selektory nie są jeszcze ustalone. Po powstaniu HTML zastąp ten schemat rzeczywistym rozmieszczeniem, opisz warunki widoczności oraz dodaj mapę konkretnych pól i przycisków.
