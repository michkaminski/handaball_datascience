# Niepoprawne żądanie — HTTP 400

Status: projekt szablonu. Plik `400.html` nie został jeszcze utworzony. Ten MD będzie znajdował się obok niego i będzie aktualizowany wraz ze zmianą szablonu.

Docelowy szablon względem katalogu szablony: `errors/400.html`.

## Przeznaczenie

Czytelna odpowiedź na błędne parametry lub niepoprawne dane wejściowe.

## Dane wejściowe

Bezpieczny komunikat oraz opcjonalny adres poprawnego powrotu. Nie wyświetlaj surowego wyjątku.

## Powiązania

Obsługa błędów HTTP w interface/errors.py, układ base.html. Odpowiedź musi mieć status 400.

## Gdzie wprowadzać zmiany

Tutaj zmieniaj treść i układ błędu. Reguły walidacji pozostają w formularzu lub klasach danych.

## Sprawdzenie zmiany

Sprawdź błędne filtry, poprawny status HTTP, bezpieczny tekst i działanie bez zapytań do bazy.

## Stan implementacji

Nie ma jeszcze bloków Jinja2, selektorów CSS ani powiązań JS do potwierdzenia. Przy implementacji zastąp ten zapis rzeczywistymi nazwami bloków, selektorów i plików testów; nie wpisuj planowanych kontroli jako wykonanych.
